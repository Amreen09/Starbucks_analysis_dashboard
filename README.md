📊💹Starbucks Sales & Beverage Analysis Dashboard | Power BI

🚀Developed an interactive Starbucks Beverage Analysis Dashboard using Power BI to analyze beverage characteristics, caffeine levels, nutritional metrics, and category-wise distribution.

🔹 Key Dashboard Features:

* Created KPI cards for Total Beverages, Average Sugar, Average Calories, and Average Caffeine
* Analyzed Average Calories by Beverage Category
* Built an interactive Beverage Category Distribution donut chart
* Analyzed Average Caffeine by Category and identified the Top 5 highest-caffeine beverages
* Added Protein Range and Beverage Prep slicers for interactive filtering
* Used images, custom colors, icons, and layout design to create a Starbucks-themed dashboard
* Applied filters and aggregations to derive meaningful insights from the dataset
